Exam Blueprint

Domain Weighting & Distribution

D1 27% (16 Qs)

Agentic Architecture & Orchestration

Agent loop stages, Single vs Multi-agent trade-offs, state machines, tool gating, and error recovery.

D2 20% (12 Qs)

Claude Code Configuration & Workflows

Project configuration (`CLAUDE.md`), permissions model, custom slash commands, hooks, and tool rules.

D3 20% (12 Qs)

Prompt Engineering & Structured Output

XML formatting, schema extraction, thinking modes, deterministic JSON generation, and prompt chaining.

D4 18% (11 Qs)

Tool Design & MCP Integration

MCP servers/clients, tool schemas, transport mechanisms (stdio/SSE), resource URI templates, and sandboxing.

D5 15% (9 Qs)

Context Management & Reliability

Prompt caching strategies, context window optimization, compaction techniques, and HITL governance.

Weekly Milestones

4-Week Structured Study Timeline

Week 1

Agentic Core & Orchestration

  • Master Agent loop perception, reasoning, and tool dispatch cycles.
  • Implement routing routers, evaluator-optimizer loops, and parallel agents.
  • Complete Domain 1 section quiz with 85%+ score.
Week 2

Claude Code & Prompt Engineering

  • Configure `CLAUDE.md` memory files and multi-directory hierarchical rules.
  • Implement robust XML tagged prompts and JSON structured schemas.
  • Complete Domain 2 & Domain 3 quizzes and review edge cases.
Week 3

Tool Design, MCP & Context Caching

  • Build Model Context Protocol (MCP) clients and stdio server integrations.
  • Apply Anthropic Prompt Caching breakpoints for token and latency savings.
  • Complete Domain 4 & Domain 5 quizzes.
Week 4

Mock Simulations & Exam Readiness

  • Take at least three full 60-question timed practice mock exams.
  • Review time pacing: aim for 80 minutes on first pass + 25 minutes review.
  • Solidify Human-In-The-Loop (HITL) safety and governance guidelines.
Tactical Playbook

Exam Day Success Tactics

⏱

Pacing Discipline

Allocate ~1.5 to 2 minutes per question. If a scenario is ambiguous, make an educated guess, flag it for review, and move forward.

🎯

Multi-Select Precision

Pay strict attention to "Select TWO" or "Select THREE" question stems. Evaluate every single option independently before confirming.

🛡

Security & HITL Default

Whenever an agent action is irreversible (e.g. database DROP, remote deployment, secret alteration), Human-In-The-Loop confirmation is mandatory.

⚡

Prompt Caching Rules

Remember that prompt caching requires exact prefix matching and minimum token thresholds (1024 tokens on Sonnet/Opus).
