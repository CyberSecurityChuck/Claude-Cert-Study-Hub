# 03 — Resume in a Fresh Chat

**When to use:** Starting a brand-new chat to continue studying. A fresh AI has no memory, so this
reloads who it is and where you are.

**Copy-paste prompt:**

```
Please act as my tutor per System_Prompt/AI_System_Prompt.md (attached). I'm continuing my Claude
Certified Architect – Foundations study.

Read the Context/Progress_Tracker.md I've attached — find the "next up" item and continue from exactly
there. First tell me my current phase, last completed section, and what's next (2–3 lines), then pick
up teaching from "next up". Teach one section at a time in simple, beginner-friendly language, and
remember I'm a total AI beginner. When we stop, give me an updated tracker block to paste in.
```

**Attach these files:**
- `System_Prompt/AI_System_Prompt.md`
- `Context/Progress_Tracker.md` (your latest version)
- The relevant `Knowledge/0X_*.md` file if you're mid-topic (e.g.
  `Knowledge/01_Agentic_Architecture_and_Orchestration.md`)
