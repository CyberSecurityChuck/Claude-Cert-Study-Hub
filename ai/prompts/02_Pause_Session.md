# 02 — Pause / Stop a Session

**When to use:** Any time you need to stop (break, message limit, out of time). Send this before you
close the chat so you never lose your place.

**Copy-paste prompt:**

```
I need to pause here. Before we stop, please:

1. Summarize in a few bullet points what we covered this session.
2. Give me an updated Context/Progress_Tracker.md block I can paste in — set the "last completed
   section", set a clear "next up", update "last session date", and tick any checkboxes / add any
   scores per the update instructions inside that file. Don't delete history.
3. State in one line EXACTLY where we'll resume next time (which file and which section/topic).
```

**Attach these files:**
- `Context/Progress_Tracker.md`
